# Расписание · КФУ

Веб-приложение с расписанием занятий: тёмное «жидкое стекло», аврора-градиенты,
точечно-матричные цифры, штриховые шкалы с жёлтым маркером и пружинные анимации.
Есть светлая пастельная тема.

## Возможности

**Регистрация (онбординг)**
- 5 шагов: имя → выбор группы с поиском → подгруппа → тема и акцент → сводка
- Прогресс шагами с dot-matrix счётчиком и живым предпросмотром «пар на неделе»
- Запускается при первом входе, повторно — из настроек («Пройти настройку заново»)

**Расписание**
- Режимы **День**, **Неделя** и **Сводка**, нижний плавающий док
- Полоса дней с точками-индикаторами занятости
- Карточка «Идёт сейчас» / «Следующая пара»: dot-matrix отсчёт, шкала прогресса
- Шкала учебного дня, перерывы между парами, бейджи подгруппы, чётности и ЦОР
- Автоматический учёт периодов курса, исключений (6.10–13.10) и чёт./неч. недель
- Детали пары: место, преподаватель, периодичность, экспорт одного занятия в календарь
- Навигация: свайпы, стрелки, клавиши `←` `→`, `T` — сегодня, `W` — неделя/день

**Сводка**
- Пары и часы на неделе, прогресс семестра, пройденные занятия
- Нагрузка по дисциплинам, категории, преподаватели

**Выбор группы**
- Шторка с поиском по коду, направлению и курсу, группировка по институту

**Настройки**
- Имя профиля и повтор онбординга
- Подгруппа: все / 1-я / 2-я
- Тема: тёмная / светлая / авто, 6 акцентных цветов
- Компактные карточки, цвета дисциплин
- Что показывать: преподаватель, аудитория, период, пустые дни, физкультура
- Чётность первой недели семестра, скрытие отдельных дисциплин
- Экспорт всего семестра в `.ics` (Apple Календарь, Google Calendar)
- Сброс настроек; всё хранится в `localStorage`

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview
```

## Структура

```
src/
  data/groups.js        # расписание групп, семестр, категории дисциплин
  lib/schedule.js       # даты, чётность недель, фильтры, статистика, экспорт .ics
  hooks/useSettings.js  # настройки + тема + акцент (localStorage)
  components/
    Onboarding.jsx      # регистрация: имя, группа, подгруппа, оформление
    DotNumber.jsx       # точечно-матричные цифры 5×7
    Ticks.jsx           # штриховые шкалы с жёлтым маркером
    Dock.jsx            # нижняя навигация
    StatsView.jsx       # экран «Сводка»
    LessonCard.jsx  GroupSheet.jsx  SettingsSheet.jsx  LessonSheet.jsx
    Sheet.jsx  Segmented.jsx  Rows.jsx
  App.jsx               # экраны «День» / «Неделя» / «Сводка»
  styles.css            # дизайн-система (токены, стекло, аврора, темы)
```

## Данные

Расписание группы **04.1-101 «Востоковедение и африканистика»** (осенний семестр 2026/2027)
перенесено с сайта kpfu.ru. Группы 04.1-108 и 04.1-204 добавлены для демонстрации
переключения — их данные условные и помечены в интерфейсе как «демо».

Чтобы добавить свою группу, допишите объект в массив `GROUPS` в `src/data/groups.js`.
