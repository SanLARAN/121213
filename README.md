# Расписание · КФУ

Веб-приложение с расписанием занятий в стиле Apple: стеклянные панели, крупные заголовки,
сегментированные контролы, пружинные анимации, светлая и тёмная темы.

## Возможности

**Расписание**
- Режимы **День** и **Неделя**, полоса дней с точками-индикаторами занятости
- Карточка «Идёт сейчас» / «Следующая пара» с обратным отсчётом и прогрессом
- Перерывы между парами, бейджи подгруппы, чётности недели и ЦОР
- Автоматический учёт периодов курса, исключений (например 6.10–13.10) и чёт./неч. недель
- Детали пары: место, преподаватель, периодичность, экспорт одного занятия в календарь
- Навигация: свайпы, стрелки, клавиши `←` `→`, `T` — сегодня, `W` — неделя/день

**Выбор группы**
- Шторка с поиском по коду, направлению и курсу, группировка по институту

**Настройки**
- Подгруппа: все / 1-я / 2-я
- Тема: авто / светлая / тёмная, 6 акцентных цветов
- Компактные карточки, цвета дисциплин
- Что показывать в карточке: преподаватель, аудитория, период, пустые дни, физкультура
- Чётность первой недели семестра
- Скрытие отдельных дисциплин
- Экспорт всего семестра в `.ics` (Apple Календарь, Google Calendar)
- Сброс настроек; всё сохраняется в `localStorage`

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview
```

## Структура

```
src/
  data/groups.js      # расписание групп, семестр, категории дисциплин
  lib/schedule.js     # даты, чётность недель, фильтры, статистика, экспорт .ics
  hooks/useSettings.js# настройки + тема + акцент (localStorage)
  components/         # Sheet, Segmented, Rows, LessonCard, GroupSheet, SettingsSheet, LessonSheet
  App.jsx             # экраны «День» и «Неделя»
  styles.css          # дизайн-система (токены, светлая/тёмная тема)
```

## Данные

Расписание группы **04.1-101 «Востоковедение и африканистика»** (осенний семестр 2026/2027)
перенесено с сайта kpfu.ru. Группы 04.1-108 и 04.1-204 добавлены для демонстрации
переключения — их данные условные и помечены в интерфейсе как «демо».

Чтобы добавить свою группу, допишите объект в массив `GROUPS` в `src/data/groups.js`.
