# КУГО-СТАНТ 🛴

Физическая «залипалка» про стант на электросамокатах и электропитбайках **Kugoo**.
Возишь посылки как курьер, крутишь флипы над колхозными полями, разбираешь ящики,
уворачиваешься от «Ларгусов» и прокачиваешь деку до состояния «не останавливается».

Игра написана на чистом JavaScript (ES-модули) + Canvas 2D, **без сборки и зависимостей**.
Вся физика — собственная: пружинная подвеска со слип-моделью колеса, вилли/стоппи,
воздушный контроль, рэгдолл при аварии. При вылете с трамплина самокат подкидывает
назад (нос вверх) — тем сильнее, чем больше газ.

## Как запустить

Любой статический сервер, например:

```bash
python3 -m http.server 8000
# открой http://localhost:8000
```

## Управление

| Клавиша | Действие |
|---------|----------|
| `→` / `D` | газ |
| `←` / `A` | тормоз / задний ход |
| `↑` / `W` | наклон назад — вилли и бэкфлип |
| `↓` / `S` | наклон вперёд — стоппи и фронтфлип |
| `Space` | нитро-буст |
| `E` | поза: присесть → без рук → супермен |
| `R` | рестарт с чекпоинта |
| `Esc` / `P` | пауза |

На телефоне — экранные кнопки.

## Геймплей

- **Комбо**: копится в воздухе и в вилли. Чисто приземлился — комбо уходит в деньги и нитро.
  Упал — сгорело. Цепочка трюков повышает множитель до ×5.
- **Доставки**: подбери жёлтую 📦 и довези до зелёной точки. Быстрее — больше премия.
- **Трюки**: бэк/фронтфлип, эйр, вилли, стоппи, без рук, супермен, скраб, мёртвая петля.
- **Ящики** ломаются, «впритирку» с машиной даёт бонус, арматура в котловане — минус самокат.
- **Батарея** садится от газа; нитро жрёт её вчетверо быстрее. Отпустил газ — заряжается.

## Парк и тюнинг

Восемь аппаратов в трёх стилях: городские (Mini Kid, M2 Pro, S3), внедорожные
(M4 Pro, Kirin X2, G-Booster) и эндуро/питбайки (Kugoo Wish 01, Pit Bike V5).
Силуэты и детали каждого стиля сверены с реальными фото Kugoo.
В гараже — «железо» (мотор, батарея, колёса, подвеска, рама — всё влияет на физику)
и «стиль» (покраска, неон, диски, короб курьера, обвес).

## Структура

```
index.html          разметка + HUD + экраны
css/style.css       интерфейс
js/config.js        физика, самокаты, тюнинг, трюки
js/utils.js         математика, рандом, звук (WebAudio)
js/physics.js       частицы + связи (рэгдолл)
js/vehicle.js       самокат, подвеска, райдер
js/terrain.js       генератор трасс и коллайдеры
js/render.js        отрисовка (небо, параллакс, самокат, эффекты)
js/game.js          игровой цикл, трюки, комбо, доставки
js/ui.js            меню, гараж, HUD, тач-кнопки
js/save.js          сохранение (localStorage)
tools/headless-test.mjs  автопрогон физики без браузера (node)
tools/check-previews.mjs рендер превью всех 8 моделей через ui.drawPreview (node)
tools/snapshot.mjs       пишет кадры рендера в JSON
tools/rasterize.py       JSON → PNG (нужны Pillow+numpy, только для проверки)
```

## Проверка

```bash
node tools/headless-test.mjs   # физика: разгон, прыжки, флипы, рэгдолл, устойчивость, эксплойт-W
node tools/check-previews.mjs  # превью всех 8 моделей без исключений
```

Тесты гоняют **настоящий** игровой код: генерацию трасс, заезд на автопилоте,
трамплин с зачётом флипа, рэгдолл, 60 секунд устойчивости по холмам и регресс
эксплойта «держать W на месте» (очков быть не должно, а вили в движении — даёт).
