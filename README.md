# ⚔ Калькулятор фэнтези Dota 2 — 2026

Удобный и точный калькулятор очков фэнтези Dota 2: система Compendium **The International 2026** (эмблемы, разряды, свойства, титулы) + классическая система Valve для лиг.

## Возможности

### 🛡 Compendium TI 2026
- Три знамени: **Основа** (пара кор-игроков), **Центр** (мид), **Поддержка** (пара саппортов) — с правилом «среднее пары».
- Групповая стадия (3 эмблемы) и Main Event (5 эмблем) — переключение.
- Все **18 показателей** с официальными значениями (убийства 107, смерти 1950−195×смерть, крипы 3, GPM ×2, тимфайт 2124×доля, Рошан 1172 и т.д.).
- **Разряды** I–V (+10…+150%) и **свойства** (Фрактальная, Благотворная, Вампирическая, Уникальная, Дружелюбная) — проценты на эмблемах считаются автоматически, включая влияние на соседей.
- **Тренерский титул**: 8 префиксов + 8 суффиксов, редактируемые проценты, активация по картам.
- Серия = сумма **двух лучших карт**; ★ отмечаются зачётные карты, худшая отбрасывается.
- Разбор очков по каждой эмблеме, итог по знамёнам и ростеру.

### 📊 Классика (Valve)
- Официальная таблица (K +0.3, D −0.3, A +0.15, LH +0.003, GPM/XPM +0.002, станы, лечение, башни, Рошан, первая кровь, варды, стаки, руны, тимфайт ×3).
- Форматы Bo1/Bo2/Bo3/Bo5 (лучшие N карт), множитель турнира (премиум 100% / профи 25% / свой).
- Все коэффициенты редактируются.

### Общее
- Автосохранение в браузере (localStorage), кнопка «Заполнить пример», копирование итога в буфер, адаптивная вёрстка, вкладка «Правила» со всеми таблицами и источниками.

## Запуск

Один файл, без зависимостей:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

или просто открыть `index.html` двойным кликом.

## Точность

Значения и механика сверены с правилами фэнтези TI 2026 (Compendium) и официальной таблицей Valve (см. вкладку «Правила и источники» в приложении). Порядок применения «разряд+свойство» и «префикс+суффикс» Valve документирует не полностью — в настройках калькулятора есть переключатель (по умолчанию — аддитивно, как отображается в клиенте). Проценты роллов варьируются, поэтому все значения редактируемы.
